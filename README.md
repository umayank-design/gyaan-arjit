# GyaanArjit

### Your Personal AI Tutor

**Learn it. Understand it. Own it.**

GyaanArjit is an AI-powered learning platform for students in Classes 5–10, designed to provide personalised tutoring, doubt clearing, assignment assistance, adaptive practice and learning intelligence.

## Initial Scope

- Classes: 5–10
- Board: CBSE
- Subjects: Mathematics, Science, English, Social Science and Hindi
- Market: India

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- AI Agent Architecture
- Retrieval-Augmented Generation
